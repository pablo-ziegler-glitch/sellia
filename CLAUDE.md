# Sellia - Instrucciones para Claude Code

## Nomenclatura de conversaciones

**Siempre** nombra cada conversación con el prefijo `VLK` seguido de una breve descripción de lo que se modifica en esa sesión.

Formato: `VLK - [módulo/área]: [descripción breve]`

Ejemplos:
- `VLK - Stock: ajuste de inventario en tiempo real`
- `VLK - Checkout: corrección de flujo de pago`
- `VLK - Sale Screen: mejora de UI en pantalla de ventas`
- `VLK - Productos: filtro por categoría`
- `VLK - Reportes: exportación a Excel`
- `VLK - Auth: fix de login con Google`

Esta convención aplica a **todas** las sesiones de trabajo en este proyecto.
